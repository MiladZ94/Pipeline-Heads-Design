Step-by-Step Guideline

PHASE 0 — Collect Inputs (from Pipelay Analysis / client)
  • DN [in], pipe grade, t_pipe
  • F_nom [kN], DAF, dynamic load F_DL
  • P_hydro [MPa], head weight W [t]
  • Head types (A: SU/LD, B: A&R, C: WBR), sling angles (5°+5°)
  • Shackle available (WLL, pin Ø)
PHASE 1 — Materials (decision table)
  • Pipe → API 5L (match line grade)
  • Plates → EN 10025 S355J0/J2
  • Flange → ASTM A694 F52/F60/F65
  • Bolts → A193 B7 PTFE · Nuts → A194 2H · Gasket → KaMOS RTJ
PHASE 2 — Design Load (LRFD)
F_SD = max(F_nom × DAF, F_DL)   →   F_d = F_SD × γc × γf
  • γc=1.30, γf=1.30, DAF≈1.4 (DNV Table 16-1)
  • Apply 5° in-plane + 5° out-of-plane components
  • Shackle: WLL ≥ F_SD
PHASE 3 — Preliminary Sizing
  • D_pin from shackle catalog → D_hole = D_pin + GAP (GAP ≥ max(2mm, 3%D_pin))
  • t_main ≈ F_d/(σ_allow·D_pin) first guess
  • R_pad ≈ 1.5·D_hole, t_cheek ≈ 0.5·t_main
PHASE 4 — Run the 10 checks (see Checks tab)
  • Bearing → Tear-out → Cheek weld → Main weld → Sections 0-0..3-3 → Closure plate → Pig stopper → Threadolet → Lifting padeye → Shroud
PHASE 5 — Deliverables
  • Drawing: assembly + details + BOM
  • Report: 1 Intro · 2 Defs · 3 Refs · 4 Scope · 5 Summary (UC table!) · 6 Design data · 7 Methodology · 8 Results · 9 Appendices
