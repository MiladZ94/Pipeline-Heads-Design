Lessons — The 10 Design Checks

Each lesson: what it protects against · the formula · variable meaning · worked example · acceptance.
1
Bearing / Contact Stress
DNV-ST-N001 §P2.7
Purpose: prevents localized yielding where the shackle pin presses against the padeye hole (incl. cheek plates).
Formula — concentrated contact if $D_p/D_h < 0.94$
$$\frac{\sigma_y}{\gamma_m} \ge 0.18\sqrt{F_d \left(\frac{1}{D_p}-\frac{1}{D_h}\right)\frac{E\beta}{t}}$$
Formula — conforming contact if $D_p/D_h \ge 0.94$
$$\frac{\sigma_y}{\gamma_m} \ge 0.045\sqrt{\frac{F_d\, E\, \beta}{D_h\, t}}$$
Variables: $F_d$ design load [N] · $D_p$ pin Ø [mm] · $D_h$ hole Ø [mm] · $E$ modulus [MPa] · $t$ plate thickness [mm] · $\beta$ contact factor (≈1) · $\gamma_m = 1.15$
Worked example (8" A-head): $F_d=887$ kN, $D_p=57$, $D_h=59$, $E=210000$, $t=40$ mm → bearing stress 262 MPa ≤ 300 = σy/γm → UC = 0.87 PASS
2
Tear-Out (Shear-Out) Resistance
DNV-ST-N001
Purpose: prevents the pin from shearing through the material between hole and plate edge.
Formula
$$\frac{\sigma_y}{\gamma_m} \ge \frac{1.7\, F_d}{(2 R_{pad} - D_h)\, t}$$
Variables: $R_{pad}$ padeye radius [mm] · $D_h$ hole Ø · $t$ plate thickness · $1.7$ empirical factor (DNV)
Example: 82 MPa ≤ 300 → UC = 0.27 PASS
3
Cheek Plate Welds
DNV-ST-N001
Purpose: verifies the fillet weld joining cheek plates to the main plate.
Formula
$$\frac{\sigma_y}{\gamma_{mw}} \ge \frac{F_d\, t_{ch}\, \delta}{1.5\, t\, D_{ch}\, a} \qquad \delta = \frac{4\tan(v)\,h}{t}+1$$
Variables: $t_{ch}$ cheek thickness · $D_{ch}$ cheek Ø · $a$ weld throat · $h$ weld height · $v$ angle · $\gamma_{mw}=1.30$
Example: 114 MPa ≤ 265 → UC = 0.43 PASS
4
Main Plate → Pipe Weld
DNV-ST-N001 · directional
Purpose: the critical weld between padeye main plate and pipe, under $F_d$ + in-plane/out-of-plane moments.
Formula — directional (von Mises) method
$$\sqrt{\sigma_\perp^2 + 3\left(\tau_\perp^2 + \tau_\parallel^2\right)} \le \frac{f_u}{\gamma_{mw}}$$
Variables: $\sigma_\perp$ normal stress on throat · $\tau_\perp,\ \tau_\parallel$ shear components · $f_u$ ultimate strength · $\gamma_{mw}=1.30$
Example: 132 MPa ≤ 346 → UC = 0.38 PASS
5
Sectional Verifications (0-0 … 3-3)
EN 1993-1-1 §6.2
Purpose: combined axial + bending + shear at critical cross-sections of the head (Fig. lateral view).
Formula
$$\frac{\sigma_y}{\gamma_m} \ge \sqrt{(\sigma_{axial}+\sigma_{bend})^2 + 3\,\tau_{shear}^2}$$
Variables: $\sigma_{axial}$ from $F_d$ · $\sigma_{bend}$ from 5°+5° moments · $\tau_{shear}$ transverse · $\gamma_m=1.15$
Example (section 3-3, worst): 225 MPa ≤ 300 → UC = 0.75 PASS. Always check ALL sections.
6
Closure Plate
Roark Table 11.2
Purpose: solid semicircular plate at the pipe end, fixed straight edges, loaded by hydrotest pressure.
Formula — radial bending stresses at A, B, C
$$\sigma_A = -0.42\, P_{LD}\frac{a^2}{t^2} \qquad \sigma_B = -0.36\, P_{LD}\frac{a^2}{t^2} \qquad \sigma_C = +0.21\, P_{LD}\frac{a^2}{t^2}$$
Acceptance
$$UC = \frac{\max(|\sigma_A|,|\sigma_B|,|\sigma_C|)}{f_{yd}} \le 1 \qquad P_{LD}=\gamma_Q P_{hydro},\ f_{yd}=\frac{f_y}{\gamma_m}$$
Variables: $a$ plate radius · $t$ thickness · $P_{hydro}$ hydrotest pressure · $\gamma_Q=1.50$, $\gamma_m=1.15$
Example: max 66 MPa ≤ 300 → UC = 0.22 PASS
7
Pig Stopper
Design
Purpose: stops the pig from exiting the pipe end during flooding/gauging.
Formula
$$\sigma = \frac{F_d}{A_{effective}} \le \frac{\sigma_y}{\gamma_m}$$
Example: 109 MPa ≤ 291 → UC = 0.37 PASS
8
Threadolet Weld
EC3
Purpose: weld of the vent/pigging threadolet under hydrotest pressure.
Formula — simplified method
$$\frac{P\, \gamma_Q\, A_{hole}}{A_{weld}} \le \frac{\sigma_u}{0.9\,\gamma_{mw}\sqrt{3}}$$
Example: 17 MPa ≤ 232 → UC = 0.07 PASS
9
Lifting Padeye (all heads)
DNV-N001 · DAF 2.44
Purpose: handles the head weight during handling.
Design load & checks
$$F_d = \gamma_Q \cdot DAF \cdot W_{max} \qquad f_p = \frac{F_d}{D_{ph}\, t} \le \frac{\sigma_y}{\gamma_m} \qquad \tau_{Ed}=\frac{F_d}{A_{shear}}\le\frac{\sigma_y}{\gamma_m\sqrt{3}} \qquad \sigma_{weld}=\frac{F_d}{A_{weld}}\le\frac{f_u}{0.9\gamma_{mw}\sqrt{3}}$$
Variables: $W_{max}$ head weight · $\gamma_Q=1.50$ · $DAF=2.44$ · $\gamma_m=1.15$ · $\gamma_{mw}=1.30$
Example: bearing 192 ≤ 300 (0.64) · shear-out 96 ≤ 173 (0.55) · weld 84 ≤ 232 (0.36) — all PASS
10
Shroud (Start-up / Laydown)
DNV-N001 + EC3
Purpose: protects the head on the roller during lay; checks bending + clamp bolts + torque.
Bending & bolts
$$M_{max}=\gamma_Q R_v\frac{L}{4} \qquad \sigma_{bend}=\frac{M_{max}}{W} \le \frac{\sigma_y}{\gamma_m} \qquad F_{AX}=\gamma_Q R_v(\tan\theta+\mu_{roll})$$ $$R_d=\frac{1}{\gamma_m}\mu_{clamp}T_b \qquad T_b = 0.70\, f_{ub}\, A_s \qquad M_{torque}=k\,d\,T_{sel}$$
Variables: $R_v$ roller load · $L$ span · $W$ section modulus · $\theta=14°$ · $\mu=0.3$ · $T_b$ bolt pretension · $k=0.2$ torque coefficient
Example: M24×8 bolts, bending 36 ≤ 309 → UC = 0.12 PASS

Step-by-Step Guideline

PHASE 0 — Collect Inputs (from Pipelay Analysis / client)
  • DN [in], pipe grade, t_pipe
  • F_nom [kN], DAF, dynamic load F_DL
  • P_hydro [MPa], head weight W [t]
  • Head types (A: SU/LD · B: A&R · C: WBR), sling angles 5°+5°
  • Shackle (WLL, pin Ø)
PHASE 1 — Materials
  • Pipe → API 5L · Plates → S355J0/J2 · Flange → A694 F52/60/65
  • Bolts → A193 B7 PTFE · Nuts → A194 2H · Gasket → KaMOS RTJ
PHASE 2 — Design Load (LRFD)
$$F_{SD} = \max(F_{nom}\cdot DAF,\ F_{DL}) \quad \longrightarrow \quad F_d = F_{SD}\cdot\gamma_c\cdot\gamma_f$$
  • γc = 1.30, γf = 1.30, DAF ≈ 1.4 (DNV Table 16-1)
  • Apply 5° in-plane + 5° out-of-plane components
  • Shackle: WLL ≥ F_SD
PHASE 3 — Preliminary Sizing
  • D_pin from shackle catalog → D_hole = D_pin + GAP, GAP ≥ max(2mm, 3%D_pin)
  • t_main ≈ F_d/(σ_allow·D_pin) · R_pad ≈ 1.5·D_hole · t_cheek ≈ 0.5·t_main
PHASE 4 — Run the 10 Checks (🎓 Lessons tab)
  • Bearing → Tear-out → Cheek weld → Main weld → Sections → Closure → Pig stopper → Threadolet → Lifting → Shroud
PHASE 5 — Deliverables
  • Drawing: assembly + details + BOM
  • Report: Intro · Defs · Refs · Scope · Summary (UC table!) · Design data · Methodology · Results · Appendices
